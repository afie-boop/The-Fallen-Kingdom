# Asset credits and licence note

The images in this folder were prepared from reference sheets supplied by the project owner
(ruined houses, sea water, beach sand, pixel characters, beggars, zombies, citizens, builders, archers and trees). They were cropped,
background-removed and down-scaled for the game; `characters/zombie_01.png` is a green recolour of
`char_07.png`.

**The original artists / licences were not stated.** Before publishing the game (GitHub, Play Store),
confirm you have the right to use and redistribute these images, or replace them with assets you own
or that have a clear licence. Replacing a file with another PNG of a similar size is enough - no code changes.

Generated in code (no external source): the castle, Zombie Castle and coin sprites (`scripts/pixel_art.gd`).

`terrain/grass.png` and `terrain/dirt.png` are NOT taken from supplied images: they were generated
procedurally (a large non-repeating grass picture and a seamless bare-soil texture).

`characters/beggar_01..11.png` and `characters/zombie_01..11.png` come from the two character sheets supplied by the project owner
(licence unknown - same note as above). The tent, campfire and zombie nest sprites are generated in code (`scripts/pixel_art.gd`).

`characters/citizen_*.png`, `builder_*.png` and `archer_*.png` come from the three character sheets supplied by the project owner (licence unknown).
Walls, archer post and builder hut sprites are generated in code (`scripts/pixel_art.gd`).
